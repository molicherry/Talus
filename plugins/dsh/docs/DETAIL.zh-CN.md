填写当前 profile 所用 Talus 的 **HTTPS** 基础地址和 API key，然后点击**保存**。
修改对后续请求立即生效。

密钥由 dsh credentials 服务保存，不下发给模型或其 shell。同一地址下留空保留原密钥；
使用清除选项并保存可移除密钥。修改地址时需要填写新目标的密钥。宿主在 TLS 内添加
`X-API-Key`，不跟随重定向。

旧安装升级后需在此重新输入一次密钥。旧设置和密钥环境变量均不再使用；保存时清除
旧密钥字段。

使用 `talus` skill 和 `talus_request` 进行服务器管理、SSH 命令、监控、文件和服务代理
操作，仍遵守现有 Talus 权限。插件自动启动凭据代理，无需 API key shell 环境变量。
二进制上传和下载使用随包助手，不通过宿主工具传入本地文件路径。

默认本地凭据提供器使用仅所属用户可访问的文件，不是 OS 加密钥匙串；强隔离同用户
进程仍需操作系统权限边界。
