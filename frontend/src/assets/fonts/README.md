# Inter font (self-hosted)

`inter-latin.woff2` is the Inter variable font, latin subset (v20), served by
Google Fonts under the SIL Open Font License 1.1.

- Font: Inter by Rasmus Andersson — https://rsms.me/inter/
- License: SIL OFL 1.1 — https://openfontlicense.org/
- Copyright: 2016 The Inter Project Authors — https://github.com/rsms/inter

Self-hosted so the dashboard makes no requests to Google Fonts (privacy for a
self-hosted tool) and avoids the render-blocking external `@import`.
The full OFL license text is available at the Inter repository above.
